# CA Helper

Small, simple tools for an Indian GST consultant whose daily work runs on Tally and Excel.

Each tool is its own folder of plain HTML, CSS and JavaScript. There is no server and no build step: open the tool's `index.html` in a browser.

| Tool | What it does |
| --- | --- |
| [counter-reconciler](counter-reconciler/) | Applies one amount per row to every row of each account's sheet (e.g. Consultation, Lab, Pharmacy of a nursing home), flags rows with amount left or short, and downloads cleaned sheets plus a combined workbook. |
